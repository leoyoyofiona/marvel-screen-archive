# 漫威所有相关作品全集欣赏

有些电影，我们已经知道结局，却还是愿意再看一次。

或许是山洞里第一次亮起的反应堆，或许是纽约上空那次集结，也可能只是某个角色说话时，你忽然想起第一次坐进电影院的自己。

这个网站由 **LEOYOYOFIONA** 出于个人爱好整理。想给这些故事留一个可以慢慢翻阅的地方：按年代走一走，看看谁与谁一起演过什么，再写下一点自己的观影记忆。不经营会员，不售卖资源，也不把喜欢变成广告。

## 运行

Node.js 22.13+。

```sh
npm ci
npm run catalog:build
npm run catalog:validate
npm test
npm run dev
```

开发地址 `http://127.0.0.1:3199`。默认没有数据库时，互动接口明确返回不可用，不生成模拟成功结果。

如需测试本地持久化，可明确启用隔离的开发数据库：

```sh
MARVEL_LOCAL_DB=true npm run dev
```

数据保存在被 Git 忽略的 `.local/`，与任何线上网站无关。单元测试使用内存数据库，不污染开发或真实访客记录。生产环境无论如何不会启用这一后备存储。

## 独立上线配置

复制 `.env.example` 里的字段到部署平台的私密环境配置，不把真实凭证提交到 GitHub：

- `DATABASE_URL`：新建的独立 Neon 数据库，使用 TLS。
- `SESSION_SECRET`：至少 32 字符的随机签名密钥。
- `ADMIN_PASSWORD_HASH`：运行 `npm run admin:hash-password` 后得到的 scrypt 哈希，不保存明文口令。
- `NEXT_PUBLIC_SITE_URL`：实际公开站点 origin，用于同源请求校验。

Render 构建命令 `npm ci && npm run catalog:validate && npm run build`；启动命令 `npm start`。免费服务的休眠／冷启动与境外线路实际可达性必须单独验证，不能承诺“大陆所有网络都能访问”。

仓库提供 `render.yaml`。它只声明这个独立站点，不使用或修改周星驰网站的数据库、服务和环境变量。生产数据库必须另建 Neon 项目；不要复制其他项目的连接字符串。

留言默认进入待审核状态。站长可打开 `/admin`，用仅保存在部署平台环境变量中的管理口令批准、拒绝或退回留言；会话为 HttpOnly、SameSite=Strict Cookie，8 小时后失效。

## 资料与素材流程

1. `catalog:import`：从片目表导入候选项目，保留原始年份、版别、来源与哈希。
2. `catalog:enrich`：提取演职员与资料页，候选外链不自动升格为已验证来源。
3. `data/editorial.mjs`：中文整理名、逐项纠错、原创简介和已整理角色出场关系。
4. `catalog:build`：生成可审计的站点目录；`catalog:validate` 检查ID、引用与观看门槛。
5. `primary-assets.json`：官方宣传图片来源账本。下载可用性不代表版权开放；`publish:false` 的素材不会由目录生成器展示。
6. `official-index.json` 与 `official-poster-ledger.json`：Marvel 官方电影、剧集、数字节目、播客索引及宣传图来源、文件校验记录。
7. `official-episodes.json`：从 Marvel 官方数字系列页读取的唯一单集标题、简介、日期、时长和详情页；不保存临时播放清单、签名串流地址或视频文件。
8. `person-portrait-ledger.json`：真人照片的 Commons 来源、作者、许可证和本地文件哈希；无合规照片的人物使用身份头像，不冒充照片。

官方目录参考：[Marvel 电影](https://www.marvel.com/movies)、[Marvel 电视](https://www.marvel.com/tv-shows)、[Marvel 数字节目](https://www.marvel.com/watch)、[Marvel 播客](https://www.marvel.com/podcasts)。官方宣传图仍属于版权素材，并非开放许可证；照片许可仅适用于账本中明确记录的对应文件。

网络原始页面缓存不进入 Git。照片、海报、对白与音乐都必须保留权利人信息；参考图、生成概念图不能冒充真实剧照。

## 观看规则

资料来源与观看入口分开。完整影片必须逐项确认合法来源、完整内容、至少720p、无需登录／注册／订阅／付费、无强制广告／广告跳转、没有地域拦截，并由浏览器实际播放验证。任何缺项均不显示观看网址；30天未复核的入口不再通过发布校验。

预告、歌曲、采访与短片另行标注，不能用来凑“免费全片”。默认中国大陆线路不预加载 YouTube、海外字体、外部分析脚本或地图服务。
