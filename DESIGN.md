## System
- Ink #090d15, graphite #151b26, silver #f1f3f7, secondary #a9b1bf, red #ec2638.
- Modern Chinese sans-serif, wide screen media, rectangular fine-line controls. Desktop gutter clamp(24px,4.5vw,88px). Content max 1600px. Touch targets >=44px.

- Hero allowed headline: 每一个宇宙，都有值得重看的故事。 Supporting copy: 从银幕初见，到多元宇宙。按作品、角色与时间，重新走进漫威。 CTA: 进入时间长廊 / 浏览全部作品.

- Main section order: hero, rights, time corridor, archive, graph, documentaries/behind scenes, listening room, community, footer.
- Desktop timeline horizontal with scroll arrows and hover/focus poster; mobile vertical. Catalogue five columns desktop, two mobile, uniform 2:3 posters. Visible pagination/search covers complete dataset.
- Graph: open canvas 70%, detail rail 30%, character/work and real-person modes. Mobile bottom drawer, keyboard accessible list.
- Work space: poster 25%, widescreen player 75%, metadata below; tabs for stills, clips, music/dialogue; back restores archive filters.
- Community: map left, voluntary form right, empty/success/error states, moderated comments, clear disclaimer. No fabricated map locations.
- Mobile: compact header; single-column hero/detail, vertical timeline, two-column catalogue, fixed four-item text navigation, no body horizontal overflow.
